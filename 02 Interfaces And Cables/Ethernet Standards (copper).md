# 🧵 Ethernet Standards (Copper)

> [!abstract] In one line
> Copper Ethernet standards are defined in **IEEE 802.3** and cover the common speeds of **10 Mbps, 100 Mbps, 1 Gbps, and 10 Gbps**.

## 📜 IEEE 802.3

| Item | Detail |
| --- | --- |
| **Standard** | IEEE **802.3**, defined in **1983** |
| **IEEE** | Institute of Electrical and Electronics Engineers |
| **Naming** | Every copper Ethernet standard begins with **IEEE 802.3** |

![[Pasted image 20261114143504.png]]

## ⚡ The Four Copper Standards

There is one standard for each of the common copper cable speeds:

| Standard | Speed | Baseband / Cabling |
| --- | --- | --- |
| **10BASE-T** | 10 Mbps | Baseband, twisted pair |
| **100BASE-T** | 100 Mbps | Baseband, twisted pair |
| **1000BASE-T** | 1 Gbps | Baseband, twisted pair |
| **10GBASE-T** | 10 Gbps | Baseband, twisted pair |

## 🔤 Decoding the Name

| Part | Meaning |
| --- | --- |
| **10 / 100 / 1000 / 10G** | Speed in Mbps or Gbps |
| **BASE** | **Baseband** signalling |
| **T** | **Twisted pair** copper cabling |

> [!tip] Remember
> **BASE-T** = **baseband** signalling over **twisted-pair** copper. The number in front is simply the speed.

## 🧠 Quick Recap

| Topic | Fact |
| --- | --- |
| **IEEE standard** | **802.3** |
| **Year defined** | **1983** |
| **Numbers** in the name | The **speed** |
| **BASE** | **Baseband** signalling |
| **T** | **Twisted pair** |

> [!success] Key takeaway
> All copper Ethernet standards share the **IEEE 802.3** family name; only the **speed** and **wiring requirements** change.
