# 🌐 Computer Network

> [!abstract] Definition
> A digital communications network that allows **nodes** to share resources.

## 🟢 Nodes

A network is built from these core devices:

| Device | Role |
| --- | --- |
| [[Router]] | Connects different networks and LANs |
| [[Switches]] | Connects devices within the same LAN |
| [[Firewall]] | Controls traffic entering and leaving the network |
| [[Server]] | Provides services to clients |
| [[Clients]] | Requests services from servers |

> [!tip] Map of Content
> Follow the links above to explore each device in detail.

## 🔁 Servers and Clients

![[Pasted image 20261111134936.png]]

Watch the exchange between the two PCs and think about which one is the server and which one is the client. PC1 asks PC2 for the file `image.jpg`, and PC2 responds by sending the requested image.

> [!question] Who is who?
> **PC1** is the client — it requests the service.
> **PC2** is the server — it provides the service.

| Role | Responsibility |
| --- | --- |
| **Client** | Accesses a service made available by a server |
| **Server** | Provides functions or services for clients |

> [!success] Key takeaway
> Client and server are **roles**, not fixed device types. The same device can be a client in one exchange and a server in another.
