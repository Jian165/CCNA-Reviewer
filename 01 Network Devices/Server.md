# 🗄️ Server

> [!abstract] Definition
> A device that provides functions or services for [[Clients]].

## 🧩 What Servers Do

- Store and share files
- Host websites and applications
- Respond to requests from clients
- Provide centralized resources to the network

> [!example] In practice
> In the [[Network]] example, PC2 acts as the server when it responds to PC1's request and sends `image.jpg`.

> [!info] Client vs Server
> A [[Clients|client]] **requests** a service; a server **provides** it. The role depends on the exchange, not the hardware.
