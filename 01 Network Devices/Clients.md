# 💻 Client

> [!abstract] Definition
> A device that accesses a service made available by a [[Server]].

## 📋 Examples of Network Clients

| Device | Operating System |
| --- | --- |
| 💻 Laptop | Varies |
| 🖥️ Desktop PC | Microsoft Windows |
| 🍎 iMac | macOS |
| 📱 iPhone | iOS |

> [!info] Client vs Server
> A **client** requests a service; a [[Server]] provides it. These are roles — a device can act as both depending on the exchange.

> [!example] In practice
> In the [[Network]] example, PC1 acts as the client when it asks PC2 for `image.jpg`.
