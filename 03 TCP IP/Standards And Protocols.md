# 🗣️ Standards & Protocols

> [!abstract] In one line
> A **protocol** is a set of rules defining how devices communicate; a **standard** is an agreed-upon specification that all vendors follow so devices can interoperate.

## 📖 What Is a Protocol?

> [!abstract] Definition
> A **protocol** is a set of rules defining **how data should be communicated** between devices over a network. Protocols are the **languages** that computers use to communicate.

## 🌍 The Language Analogy

![[Pasted image 20261119142206.png]]

> [!example] Think of it as...
> Someone who only speaks **Chinese** cannot talk with someone who only speaks **English**. In the same way, computers that "speak" different protocols cannot exchange data.

## 🏢 The Proprietary Problem

> [!warning] Vendor-specific protocols
> Since the early days of computer networking there were several attempts to define the functions needed for computers to communicate. These protocols were often developed by a **specific vendor**, such as **IBM**, for use with its own products. With this proprietary approach, enabling communications between different vendors' products was **difficult, if not impossible**.

| Scenario | Result |
| --- | --- |
| Apple iMac + IBM server, each using proprietary protocols | The IBM server **cannot understand** a request from the iMac |
| MacBook → Linux web server | Works — both follow the same web standards |
| Windows PC → Android smartphone (email) | Works — both follow the same mail standards |

> [!info] Visual example
> The iMac/IBM server example uses modern devices only as a visual illustration — this kind of problem was common in the **early days** of networking.

## ✅ The Standard Solution

> [!important] Definition — Standard
> A **standard** is an **agreed-upon specification** that describes how a protocol or technology should work. Today's networks and devices use **standard, vendor-neutral** protocols and technologies. When devices follow vendor-neutral standards, devices of all types can communicate with each other.

> [!success] Key takeaway
> **Protocols** are the shared rules of communication; **vendor-neutral standards** make those rules common to everyone so devices from different companies can work together.

## 🧠 Quick Recap

| Topic | Fact |
| --- | --- |
| **Protocol** | Set of rules for communicating data over a network |
| **Standard** | Agreed-upon specification of how a protocol/technology works |
| **Proprietary protocols** | Vendor-specific — hard or impossible to interoperate |
| **Vendor-neutral standards** | Let any compatible devices communicate |
