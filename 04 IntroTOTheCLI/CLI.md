# 💻 Cisco IOS and the CLI

> [!abstract] Definition
> **Cisco IOS** is the operating system that runs on Cisco devices (routers, switches, firewalls) — like Windows or macOS on a PC. The **CLI** is the text interface used to configure those devices.

> [!warning] Not Apple iOS
> Cisco **IOS** is **not** related to Apple's **iOS** on iPhones. They are completely different operating systems that happen to share a name.

## 🧠 Cisco IOS

Cisco IOS is the operating system used on Cisco devices:

- Routers
- Switches
- Firewalls

It performs the same basic role for a network device that **Windows** or **macOS** performs for a computer — it runs the device and provides the interface we use to work with it.

## ⌨️ What the CLI Is

**CLI** stands for **Command-Line Interface**. It is the interface you use to configure Cisco devices by typing commands.

> [!tip] Think of it as...
> A text-based conversation with the device: you type a command, and the device responds with output or a new prompt.

## 🖼️ CLI vs GUI

| Interface | Full name | How it works | In this course |
| --- | --- | --- | --- |
| **CLI** | Command-Line Interface | Type text commands | ✅ Main focus |
| **GUI** | Graphical User Interface | Click through visual screens | ❌ Not covered |

- An example of a Cisco GUI is **ASDM**, which can be used to configure Cisco firewalls.
- GUIs are not covered in this course.
- Most network engineers **prefer the CLI** over a GUI.

> [!success] Key takeaway
> **Cisco IOS** is the OS on Cisco devices, and the **CLI** is the text interface used to configure them. Most engineers prefer the CLI over a GUI, so that is what this course uses.
